# Hardware captures

Status: current

See [the checklist](../../hardware-verification.md).

Raw hwprobe output committed per bench session. One directory per session:
`docs/hardware/captures/<YYYY-MM-DD>-<board-serial>/` holding `report.json`,
the `*.bin` raw captures and a filled-in `session.md` (template in
`docs/hardware-verification.md`, section 4). Never edit a capture after
committing it; add a new session instead.
