# Web design system: lab instrument

Status: current

Ticket ~3EMAPTS. The web UI looks like a bench instrument front panel and a printed lab
report, not a generic dashboard. Layout, DOM, class names and behaviour are unchanged; only the
visual system moved. Source of truth: `web/crunk.toml` `[palette]` (mirrored in
`web/src/theme.css`, checked by `web/src/a11y/contrast.test.ts`); `web/src/tokens.css` is
generated by `crunk tokens`.

## Palette

- Light: warm paper (`--bg #efebe0`, panels `--surface #f8f6ee`, title strips `--surface-2`),
  warm near-black ink, warm hairlines.
- Dark: deep neutral graphite (`--bg #151515`), warm off-white ink. No blue tint.
- ONE accent, deep teal (`--accent`), for primary actions, the current step and the active
  rail marker. Amber is reserved for warn/focus. Semantic ok/warn/bad (+ `-soft`) are used only
  for state; the SYNTHETIC banner stays loud red with a hazard stripe in both themes.
- All text pairs are >= 4.5:1 and control borders/focus >= 3:1 in both themes (contrast test).

## Shape and motion

Radii are 2px (`--radius-sm`) and 3px (`--radius-md`); meters, bars, pills and banners are
square. Shadows are `none`; panels are framed by 1px `--border` hairlines. No gradients (apart
from the synthetic hazard stripe), no decorative icons, near-zero motion.

## Type

System UI sans for prose. Monospace (`--mono`) with tabular numerals for ALL readouts, table
cells, IDs, step state, pills, the status bar and plot tick labels. Panel titles (first heading
of a framed section, fieldset legends, table heads, form labels, readout labels) are small
uppercase letter-spaced micro-labels like silkscreen legends. Scale (`--text-xs..xl`):
0.72, 0.8125, 0.9375, 1.125, 1.4 rem. Only font stacks are used; no web fonts.

## Panels and plots

A framed section's first `h2`/`h3` is styled as a title strip (`--surface-2`, bottom hairline).
Plots draw on a paper canvas (`#f8f6ee`) in both themes so exports match print; thin 1.25px
traces, restrained grid, monospace ticks (`src/plots/theme.ts`).
